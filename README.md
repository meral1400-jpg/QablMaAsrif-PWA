# قبل ما أصرف | QablMaAsrif

تطبيق شخصي لتنظيم الدخل والمصروفات والاحتياجات والأولويات.

**فكرة وتطوير: سلطان السلطان**

هذا المستودع يحتوي **فقط** على ملفات تطبيق الويب القابل للتثبيت على الآيفون.
لا يحتوي على معلومات المستخدمين المالية، ولا يحتاج التطبيق إلى إنشاء حساب.

- يتيح الاستخدام دون اتصال بعد فتحه أول مرة وحفظ ملفات التطبيق.
- تُحفظ بيانات كل مستخدم محليًا داخل المتصفح/تطبيق الشاشة الرئيسية.
- احتفظ بنسخة احتياطية من الإعدادات لتجنّب فقد البيانات عند حذف التطبيق.

للتثبيت على الآيفون: افتح الرابط في Safari ثم مشاركة ← إضافة إلى الشاشة الرئيسية.

ملاحظة: التذكيرات الآلية في الخلفية ليست مضمونة في نسخة الويب دون خدمات إضافية؛ استخدم ملف التقويم عند الحاجة.
